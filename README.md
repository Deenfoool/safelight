# Safelight

> Локальный image toolkit для браузера. Быстрая обработка изображений без загрузки файлов на сервер.

**Safelight** — image processing without sending your images away.

## О проекте

**Safelight** превращает браузер в небольшой графический инструмент: сжатие, конвертация, изменение размера, нарезка, коррекция и другие операции выполняются прямо на устройстве пользователя.

- Никаких аккаунтов
- Никаких загрузок изображений на сервер
- Открыл → загрузил → обработал → скачал

## Особенности

- Локальная обработка через Browser APIs / Canvas
- PNG / JPEG / WebP (+ PDF в конвертере)
- Сжатие и контроль качества
- Нарезка изображений и ZIP
- Изменение размера и обрезка
- Базовая цветокоррекция
- Поворот и отражение
- Водяные знаки
- Пакетная обработка
- Инструменты для метаданных
- Генерация favicon-пакета
- Адаптивный интерфейс
- Сравнение «до / после» в превью

## Системные требования

| Требование | Значение |
|---|---|
| ОС | Любая современная ОС |
| Браузер | Chrome / Chromium / Firefox / Edge / Safari |
| Интернет | Не нужен для самой обработки изображений* |
| Сервер | Не требуется |

\* Шрифты и некоторые библиотеки (JSZip, PDF.js) подгружаются с CDN при первом открытии. CI для GitHub Pages скачивает их в `vendor/` и переписывает ссылки.

## Установка / запуск

Safelight не требует сборщика или backend.

```bash
git clone https://github.com/Deenfoool/safelight.git
cd safelight
```

Открой `index.html` в браузере или размести репозиторий через GitHub Pages.

> Для локального открытия без CORS-ограничений удобнее использовать простой HTTP-сервер:
> `npx serve .` или `python -m http.server 8080`

## Технологии

- HTML5
- CSS3
- Vanilla JavaScript
- Canvas API
- JSZip
- PDF.js + jsPDF (для PDF-конвертации)

## Почему Safelight?

Большинство простых операций с изображениями не требуют отправки файла на удалённый сервер. Safelight использует возможности браузера и выполняет обработку локально.

Это быстрее для небольших задач и лучше с точки зрения приватности.
