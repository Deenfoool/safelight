# Safelight

> Локальный image toolkit для браузера. Быстрая обработка изображений без загрузки файлов на сервер.

![Safelight](https://dummyimage.com/1200x500/09090b/4ade80&text=SAFELIGHT)

## О игре... точнее, о проекте

**Safelight** превращает браузер в небольшой графический инструмент: сжатие, конвертация, изменение размера, нарезка, коррекция и другие операции выполняются прямо на устройстве пользователя.

Никаких аккаунтов. Никаких загрузок изображений на мой сервер. Просто открыл, загрузил, обработал, скачал.

## Особенности

- Локальная обработка через Browser APIs / Canvas
- PNG / JPEG / WebP
- Сжатие и контроль качества
- Нарезка изображений и ZIP
- Изменение размера и обрезка
- Базовая цветокоррекция
- Поворот и отражение
- Водяные знаки
- Пакетная обработка
- Инструменты для метаданных
- Генерация favicon
- Адаптивный интерфейс

## Системные требования

| Требование | Значение |
|---|---|
| ОС | Любая современная ОС |
| Браузер | Chrome / Chromium / Firefox / Edge / Safari |
| Интернет | Не нужен для самой обработки |
| Сервер | Не требуется |

## Установка

Safelight не требует сборщика или backend.

```bash
git clone https://github.com/Deenfoool/safelight.git
cd safelight
```

Открой `index.html` локально или размести репозиторий через GitHub Pages.

## Почему Safelight?

Большинство простых операций с изображениями не требуют отправки файла на удалённый сервер. Safelight использует возможности браузера и выполняет обработку локально.

Это быстрее для небольших задач и лучше с точки зрения приватности.
