# Safelight Roadmap

Этот файл фиксирует текущие приоритеты развития Safelight. К нему можно возвращаться как к основной дорожной карте проекта.

## Приоритеты

1. **Метаданные — ✅ реализовано**
   - Инспектор метаданных переработан в полноценные смысловые категории.
   - EXIF разбит на: камера и объектив, параметры съёмки, дата и время, авторство, идентификаторы, программа и комментарии, технические поля файла.
   - GPS вынесен в отдельный заметный блок с координатами, высотой и GPS-временем при наличии.
   - Добавлены предупреждения о GPS, серийных номерах, владельце камеры, дате, авторстве и комментариях.
   - У каждого значения есть копирование, плюс кнопка копирования всех распознанных значений.
   - Пресеты очистки: «Удалить GPS», «Для публикации», «Удалить всё».
   - Для JPEG поддерживается выборочное сохранение неотмеченных категорий; PNG и WebP экспортируются как чистые копии.
   - После экспорта Safelight повторно разбирает созданный файл и показывает проверенный отчёт: метаданные до/после, GPS, удалённые и сохранённые категории, оставшиеся контейнеры.

2. **Коррекция изображения — ✅ реализовано**
   - Уровни с гистограммой.
   - Чёрная, средняя и белая точки + выходные уровни.
   - Автоуровни по процентилям гистограммы.
   - Тоновая RGB-кривая с интерактивными точками.
   - Более качественная резкость через нерезкую маску: количество, радиус, порог.
   - Шумоподавление с сохранением деталей на границах.
   - Виньетка с регулировкой мягкости.
   - Технические пресеты: автоуровни, восстановление теней/светов, резкость для веба, шумоподавление.
   - Все группы собраны в раскрывающиеся секции.

3. **Обрезка — ✅ реализовано**
   - Выравнивание горизонта прямо внутри Crop: −45° … +45° с точностью 0.1°.
   - Автоматическое увеличение изображения при повороте, чтобы не появлялись пустые углы.
   - Сетки 3×3 и золотое сечение + режим без сетки.
   - Фиксированные отношения сторон: исходное, 1:1, 4:3, 3:2, 16:9, 9:16, 5:4 и 4:5.
   - Точные координаты X / Y и размеры в пикселях.
   - Двусторонняя синхронизация точных полей и интерактивной рамки.
   - Текущая интерактивная рамка сохранена как основа Crop.
   - Apply / History / Export используют итоговый кадр вместе с выравниванием горизонта.

4. **Работа с прозрачностью — частично реализовано через «Удаление фона»**
   - ✅ Выбор цвета и превращение его в прозрачность.
   - ✅ Допуск.
   - ✅ Мягкость / Feather края.
   - Удаление цветного ореола — ещё не реализовано.
   - ✅ Волшебная палочка по связанной области.

5. **Удаление фона без нейросети — ✅ реализовано**
   - Цветовой ключ по выбранному цвету с пипеткой и регулируемым допуском.
   - Magic Wand / flood fill удаляет только связанную область от точки клика.
   - Кисть «стереть / вернуть» работает по отдельной alpha-маске; «вернуть» восстанавливает исходную прозрачность.
   - Feather применяется к автоматическим выделениям и может дополнительно сглаживать готовую маску.
   - Режимы просмотра: шахматная прозрачность, белый фон, тёмный фон и сама маска.
   - Инверсия и полный сброс маски.
   - Apply записывает результат в общую историю; Undo / Redo восстанавливают рабочие версии.
   - Экспорт из инструмента ограничен PNG и WebP, чтобы сохранить alpha-канал.
   - Основной сценарий: логотипы, товары, скриншоты и изображения с однотонным или близким по цвету фоном.

6. **Аннотации**
   - Список объектов / слоёв.
   - Блокировка объектов.
   - Группировка.
   - Выравнивание.
   - Более аккуратные стрелки и подписи.

7. **Холст**
   - Направляющие.
   - Привязка к центру и краям.
   - Точное позиционирование изображения.
   - Несколько объектов на одном холсте.
   - Не превращать Safelight в полноценный Photoshop-клон.

8. **Водяной знак — ✅ реализовано**
   - Текстовый водяной знак и изображение / логотип.
   - Цвет текста и четыре локальных системных набора шрифтов без внешних загрузок.
   - Цвет и толщина обводки текста.
   - Поворот −180° … +180° для текста и логотипа.
   - Прозрачность и размер настраиваются отдельно; логотип масштабируется относительно ширины изображения.
   - Одиночный знак сохраняет прямое перетаскивание по изображению.
   - Повторяющийся паттерн получил отдельные шаги по X / Y и смещение соседних рядов.
   - Точный рендер используется при Apply и экспорте JPEG / WebP / PNG / PDF.
   - Apply сохраняет результат в общую историю действий.

9. **Пакетная обработка**
   - Цепочки действий, например:
     - Resize
     - Convert WebP
     - удалить метаданные
     - качество 82%
     - ZIP
   - Один рецепт должен применяться к большому набору файлов.

10. **Favicon Generator**
    - Светлый и тёмный preview.
    - Автоматическая оценка читаемости 16×16.
    - Предупреждение о слишком тонких или мелких деталях.
    - Сохранять текущую сильную специализацию инструмента.

11. **История действий — ✅ реализовано**
    - Выпадающий список истории в верхней панели.
    - До 20 рабочих состояний с сохранением исходника.
    - Переход напрямую к любому сохранённому состоянию.
    - Undo / Redo.
    - `Ctrl+Z` / `Cmd+Z` для Undo.
    - `Ctrl+Shift+Z` / `Cmd+Shift+Z` и `Ctrl+Y` для Redo.
    - Новое применение после Undo отбрасывает старую ветку Redo.

12. **Производительность**
    - Web Workers для тяжёлых пиксельных операций.
    - Уменьшенный интерактивный preview.
    - Полное разрешение только при Apply / Export.
    - Отдельное внимание большим изображениям 20–50 МП.

13. **Общий UX инструментов**
    - Единая логика ползунков.
    - Reset.
    - Apply.
    - Подсказки.
    - Состояния загрузки и ошибок.
    - Клавиатурные сокращения.
    - Удаление legacy-кода и дублирующих владельцев preview.

14. **PWA / Offline**
    - Проверить полный сценарий работы без сети после первой загрузки.
    - Каждый инструмент должен работать offline.
    - Экспорт тоже должен работать offline.

15. **Главная страница**
    - Не раздувать её в длинный лендинг.
    - Максимум короткий блок из трёх тезисов: «Редактирование / Подготовка для веба / Приватность».
    - Сохранять текущую минималистичную подачу.

## Три главных направления

Изначально три задачи с максимальным эффектом для всего проекта были:

1. **История действий — ✅ реализовано**
2. **Прозрачность / удаление фона — ✅ основа реализована**
3. **Прокачка пакетной обработки**

После истории и удаления фона следующий крупный системный приоритет — **пакетная обработка**. Для прозрачности остаётся отдельная доводка краёв и удаление цветного ореола.

## Пока не приоритет

- Режим «До / После».
- AI-фильтры.
- Аккаунты.
- Облачное хранение.
- Социальные функции.

Главный принцип развития: **углублять существующий редактор и его workflow, а не превращать Safelight в набор десятков поверхностных инструментов.**
