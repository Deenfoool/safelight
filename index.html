Safelight — это не облачный сервис. Загруженный файл читается через Canvas API прямо в вашем браузере: сжатие, нарезка и конвертация происходят локально, а сборка ZIP-архива с фрагментами — тоже без сети. Обновите страницу — и ничего не останется.
